# Smart Medication Reminder and Adherence Monitoring System

## Overview

This project is an IoT-based Smart Medication Reminder and Adherence Monitoring System developed using Raspberry Pi and Arduino Nano 33 IoT.

The system supports:

* Multiple patients
* Automated medication reminders
* MQTT communication
* LED and buzzer alerts
* Medication acknowledgement
* Missed dose detection
* CSV logging
* Web dashboard
* Graph visualisation
* IFTTT notifications
* Fault tolerance
* Admin access control

## Hardware

* Raspberry Pi
* Arduino Nano 33 IoT
* LED
* Passive Buzzer
* Slider Switch

## Software

* Python
* Flask
* Tkinter
* MQTT
* Mosquitto
* Matplotlib

## Running the System

Start controller:

```bash
python3 medicine_controller.py
```

Start GUI:

```bash
python3 medicine_dashboard.py
```

Start web dashboard:

```bash
python3 web_dashboard.py
```
